Commands

Core

/help List all commands
/info Get information and stats about the bot

Players

/version Fetch a Hytale profile by UUID or username
/head Get an image of a Hytale player's head
/body Get an image of a Hytale player's body
/cape Get an image of a Hytale player's cape
/skin Fetch a Hytale player's skin details

Updates

/version Get the latest Hytale versions
/launcher Get the latest Hytale Launcher version
/articles Get the latest Hytale article
/subscribe Subscribe to Hytale updates
/list-subscriptions List all subscriptions
/unsubscribe Unsubscribe from Hytale updates
